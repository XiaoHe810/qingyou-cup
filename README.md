# 东北石油大学第四届“青油杯”研究生乒乓球比赛抽签与赛事编排管理系统

系统使用 Python、Flask、Waitress 和 SQLite。浏览器通过同一服务端保存与同步状态。公开大屏约每 1.5 秒获取最新结果，掉线恢复后重新读取数据库。正式房间、验收数据库和验收导出分别存放。

## 快速启动

在本项目目录中执行。推荐 Python 3.11–3.14。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 app.py admin organizer
.\Start-Local.ps1 -Python .\.venv\Scripts\python.exe
```

首次设置管理员密码需输入两次。浏览器访问 http://127.0.0.1:8080/ 。管理员登录后可上传原始报名表建立房间。当前工作区的 `runtime/event.sqlite3` 已用真实 V2 原表建立房间，可直接使用。源代码压缩包在其他机器使用时，通过网页或以下命令重新导入。

```powershell
.\.venv\Scripts\python.exe -X utf8 app.py import 'D:\报名资料\第四届青油杯_参赛信息统计表_V2.xlsx'
```

## 群内统一入口

GitHub Pages 托管 `docs/` 入口，所有负责人和观众使用同一链接。赛事站保存抽签及比赛记录。每个学院登记后只抽一次顺序号。男子团体、女子团体、混双沿用同一学院顺序，未报名混双的学院自动跳过。全部学院抽齐后，在“比赛对阵”下载三项目合并 Excel 或 PDF。主持控制支持一键预演和归档后恢复初始状态。

## 验收复跑

```powershell
.\.venv\Scripts\python.exe -X utf8 test_acceptance.py 'D:\报名资料\第四届青油杯_参赛信息统计表_V2.xlsx' --output output
```

验收脚本使用临时 SQLite，保留原表待核验标记，模拟裁判、赛果和同分裁决。测试导出的标题和文件名含“测试”，每次复跑重新随机分配签位。

## 数据现状

- 原表 11 个参赛单位，男子团体 11 队 47 条，女子团体 11 队 45 条，混双 9 对 18 条。
- 5 对混双通过同学院、同姓名、同学号的团体报名记录交叉核验。机械科学与工程学院、石油工程学院、寒地工程学院、经济管理学院共 4 对保留性别待核验提示，按学院报名照常抽签与排程。
- 公开接口仅提供学院和赛事信息。系统保留导入行号及排程用身份键，学号、手机号只在解析时使用，不写入数据库或报表。
- 球台 4 张、预计每场 35 分钟、间隔 5 分钟、12:00 和 18:00 为示例排程参数。四强循环赛默认优先安排在最后一个比赛日。上线前按现场条件核对。
- 默认团体五单项三胜、单项三局两胜，混双五局三胜。每局 11 分、10 平后净胜两分。管理员可在开赛前调整单项数和局数。晋级阶段使用本项目约定的附加淘汰赛、八强淘汰赛、四强单循环赛。
